PRINT COLOR FIX:
The print CSS now forces exact colors/backgrounds in print output.
In Chrome/Edge print settings, also enable:
- Background graphics: ON
- Scale: 100%
- Margins: None


IMPORTANT FOR COLOR PRINT:
The website now uses exact print-color CSS and disables print-time color alteration.
However, Chrome cannot force the printer's hardware color mode.
In the Chrome print dialog shown on your screen:
1. Change "Colour" from "Black and white" to "Colour".
2. Open "More settings".
3. Set Scale = 100%.
4. Turn Background graphics = ON.
5. Keep A4 paper.
The printed card will then retain the blue, orange, navy and other colors from the live preview.
